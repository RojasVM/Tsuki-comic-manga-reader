# Tsuki-comic-manga-reader
Tsuki es una biblioteca digital y lector de cómics y mangas diseñado específicamente para entusiastas de la lectura.

A nivel técnico, Tsuki es una aplicación 100% estática que procesa la información directamente en el dispositivo del 
usuario. En lugar de depender de un servidor externo para procesar los archivos, la aplicación descarga los capítulos en 
formato .cbz (que en esencia son archivos ZIP que contienen imágenes), los descomprime de forma nativa en el navegador y 
renderiza las páginas de manera secuencial. Esto garantiza una experiencia de lectura rápida, privada y sin interrupciones.

Características Principales

- Soporte Multiplataforma: La interfaz está optimizada para adaptarse a cualquier entorno, funcionando a la perfección en Safari para iOS, navegadores nativos de Android y en sistemas de escritorio.

- Experiencia Nativa (PWA): Tsuki está construida como una Aplicación Web Progresiva. Esto significa que puedes usar la opción de "Agregar a la pantalla de inicio" en tu teléfono o tablet para instalarla y disfrutar de una experiencia inmersiva, a pantalla completa y similar a una app tradicional.

- Rendimiento Optimizado: Al delegar la extracción de las imágenes al propio navegador, se reduce significativamente la latencia y se agiliza la transición entre las páginas de tus mangas favoritos.
